## 解决hexo生成静态网页上传后文章图片无法显示问题

在编写内容的时候我们可能会需要插入图片，因为markdown中插入的图片一般是以链接或是相对地址储存在文件外的，在生成静态文件的时候，系统并不会自动在文本中生成或是储存该图片，也就导致我们的博客中图片是加载失败的，这时候有以下几种解决方案：

### 1. 绝对路径本地引用

在hexo中有专门用于储存图片的images文件夹，可以将图片存储在该文件夹内，使用该文件路径就可以在上传的文章中显示图片。

当Hexo项目中只用到少量图片时，可以将图片统一放在`source/images`文件夹中，通过markdown语法访问它们。

```text
![](/images/image.jpg)

```

需要注意的是设置图片时要小心，该文件夹的图片可以同时在文章与主页被访问。

### 2. 相对路径本地引用

图片除了可以放在统一的images文件夹中，还可以放在文章自己的目录中。文章的目录可以通过站点配置文件_config.yml来生成。
`post_asset_folder: true`将_config.yml文件中的配置项post_asset_folder设为true后，执行命令:

```text
$ hexo new post_name

```

在`source/_posts`中会生成文章`post_name.md`和同名文件夹`post_name`。将图片资源放在`post_name`中，文章就可以使用相对路径引用图片资源了。

```text
![](image.jpg)

```

![image-20220629130018217](../../assets/legacy/教程（四）-解决博客文章中图片上传失败问题/image-20220629130018217.png)

我们可以看到图中左侧为markdown文章，右侧为其同名的图片储存文件夹。

### 3. 标签插件语法引用

这种相对路径的图片显示方法在博文详情页面显示没有问题，但是在首页预览页面图片将显示不出来。如果希望**图片在文章和首页中同时显示**，可以使用标签插件语法。

```text
# 本地图片资源，不限制图片尺寸
{% asset_img image.jpg This is an image %}
# 网络图片资源，限制图片显示尺寸
{% img http://www.viemu.com/vi-vim-cheat-sheet.gif 200 400 vi-vim-cheat-sheet %}

```

### 4. 图片插件

插件[hexo-renderer-marked](https://link.juejin.cn/?target=https://github.com/hexojs/hexo-renderer-marked)解决了这个问题，我们可以使用命令安装该插件：

```text
npm install hexo-renderer-marked

```

之后在`config.yaml`中更改配置如下：

```text
post_asset_folder: true
marked:
  prependRoot: true
  postAsset: true

```

之后就可以在使用`![](image.jpg)`的方式愉快的插入图片了。我们在文本中插入图片时，插件就会自动为我们创建post_name文件夹，并且自动使用该文件夹相对路径。

### 注意

在使用相对路径后注意，将图片放入post_name文件夹中并且直接使用图片名称为路径，这样图片在markdown文本中是无法显示的，但是在静态网页中是可以显示的。
