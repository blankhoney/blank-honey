压缩小箱

把零散文件装进 ZIP 或 7z，也可以打开一个压缩包，先看清里面有什么，再挑出需要的部分。
整个过程只在这台设备上进行，文件不会上传；口令只用来解开你自己的压缩包。

打开 ZIP 或 7z

先列出清单，不会直接解压到磁盘。

    把文件打包

    拖入文件夹可保留空目录；文件夹按钮只收录浏览器返回的文件。

      选择一个 ZIP 或 7z 压缩包开始。

      文件和口令只在本机的浏览器里处理，不会上传、不会写进地址栏、日志或本地存储。关闭或清空页面即释放临时数据。
