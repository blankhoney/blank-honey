BEHIND THE LIGHT

光路由时空决定。

这是无自旋、无电荷黑洞的广义相对论光线追踪。每个像素从静止观测者的局部正交标架出发，反向寻找光源。

ds² = −(1 − 2/r)dt² + (1 − 2/r)⁻¹dr² + r²dΩ²
u″ = −u + 3u²   ·   u = 1/r   ·   ds² = 0

GPU 用四阶 Runge–Kutta 积分轨道与光行时，在盘面交点精确落步。引力透镜、捕获阴影及高阶盘面像由路径自然形成。阴影的临界冲量参数为 bc = 3√3 rg，不等于事件视界半径。

光源与成像

不透明薄盘位于 6–22 rg，采用零扭矩 Novikov–Thorne 径向通量。Ω = r−3/2；发射纹理按光行时回溯，并随轨道差速旋转。频率比 g 由发射体四速度和光子的守恒角动量计算。

g = √(1 − 3/r) / [√(1 − 2/R) (1 − Ωλ)]

可见光模式积分红移后的普朗克光谱 Bν(gT) 与 CIE 1931 配色函数；伪彩模式使用 g⁴F 的总辐射强度。辉光与曝光属于显示处理，可关闭辉光。

适用边界

固定 Schwarzschild 背景；未模拟 Kerr 自旋、磁场、流体动力学、盘厚、散射与自照明。盘面纹理和背景星空为程序生成。峰值温度决定通量归一化，调节它相当于改变吸积率。M = 10⁹ M☉ 时，rg ≈ 9.87 AU，tg ≈ 4,926 s；动画时间经过加速。

积分最多 1,536 步 / 8π 弯转角，临界曲线附近不能分辨无限高阶像。空间采样和 32 位浮点精度也有限；“光路”模式用品红标记未收敛光线。此页面不声称达到科研级 GRMHD 保真度。
