# Blank Honey 个人站点 PRD

- 版本：v1.3 终版
- 日期：2026-09-12
- 用途：产品范围冻结。架构与程序设计不得自行加面或改验收。
- 施工模型：Agent 一次实现全量，质量靠 code review，不分 P0/P1/P2。

---

## 0. 文档约定

- 只写要什么、不要什么、验收长什么样。
- 不写代码骨架，不写分批交付清单。
- 能用业界公认方案就用，不发明新协议、新内容类型。
- 不为“看起来完整”自行加需求。
- 优先级：本 PRD 的产品范围 ＞ 架构的系统边界 ＞ 程序设计的实现合同。

## 1. 产品定义

### 1.1 一句话

Blank Honey 是个人站点。第一眼是可随机切换的炫彩首屏；站点主体是文章、探针、旅游地图、知识图谱、工具展示和实验室索引。

### 1.2 两层同等重要

| 层 | 内容 | 要求 |
|---|---|---|
| 门面 | 首页随机效果库 + 名字 / 简言 | 第一眼要炫、默认干净、刷新可不同 |
| 主体 | 文章、探针、地图、图谱、工具、实验室 | 博客本身，不是藏起来的彩蛋 |

次要、默认可收：效果选择、搜索、音乐、主题、减少动效、关于我 / GitHub、回看首屏。

第一版不做：公开统计面板、按阅读量排序、留言板、世界钟独立模块、访客自建电台。

### 1.3 成功标准

- 刷新首页抽到不同效果；`?effect=` 能复现；选择栏能左右挑
- 文章选择页按分类分块，每块最近 3–4 篇；分类标题进入该分类归档
- 能发 Markdown；分类 / 标签可聚合；有 RSS / sitemap
- 阅读页沉浸：目录默认折叠；上一篇 / 下一篇在评论前；Giscus 在文末
- 实验室索引每条有标题和介绍，不是裸链接；实验跑在独立域名
- 探针实时看到约 4～5 台：在线、CPU、内存、Swap、磁盘、负载；每台带地区与当地时间
- 地图：未去过灰、去过点亮；可缩放；放大到阈值才出地标
- 知识图谱单独一页，只展示已确认关系
- 工具页卡片进入自有域名
- 音乐只选预置台；进站意图为开，被浏览器拦则待一次点击；访客不能加台
- 观测走 OpenTelemetry 主机指标；站点错误写本地日志，不接第三方 APM
- 内容可备份可迁；后台与上传不走公网
- 手机能用；粒子有档位；尊重 `prefers-reduced-motion`

### 1.4 品牌

- 署名：Blank Honey
- 简言：英文、偏古、和时间 / 努力有关，不超过 10 词
- 候选池随机抽取，由 agent 改配置追加
- 起步候选：Tempus fugit / Labor omnia vincit / Ars longa, vita brevis / Per aspera ad astra
- 名字与简言纯色。动效跟具体 Hero 走，全站不写死

### 1.5 风格锚点

抄气质不抄整站。背景可以炫，前景必须克制。

| 站点 | 借什么 |
|---|---|
| https://io724.com | 极简首屏 + 强背景 |
| https://miniload.top | HUD 气质、名字与简言的动态感；不要单字母抖动 |
| https://isaca.pro | 安静留白、索引式极简 |
| https://ios25span.com | 加载 / 预热思路，后续页不要做重 |
| http://yantao.wiki | 粒子 + 技术博客信息密度 |

阅读页：暖纸印刷感。功能页：硬终端 / 点阵，不要霓虹赛博。

## 2. 设计原则

1. Agent 一次做完需求面，用 review 管质量。
2. 门面炫，主体完整。
3. DDD + 整洁架构：限界清楚，单向依赖。
4. 组合优于自研。组件必须仍在维护、被广泛使用。
5. 内容用 schema.org，主机观测用 OpenTelemetry。
6. 首页效果每次刷新随机，不记上次手选。
7. 效果模块可增，不设数量上限。
8. 最终必须有性能收口。
9. 可备份、可迁移。公网不能传文件。

## 3. 信息架构

主入口叙事：

1. `/` 第一屏：随机 Hero
2. `/articles/` 第二屏：文章选择，博客真正起点
3. 打开侧栏后进入探针、地图、图谱、工具、实验室

深链接、RSS、搜索结果不强迫先看 Hero。

| 页面 | 视觉 | 说明 |
|---|---|---|
| `/` | Hero 独立语言 | 随机效果 + 名字 + 简言 |
| `/articles/` | 暖纸 | 分类分块；页脚极淡「回看首屏」 |
| `/category/<slug>/` | 暖纸 | 该分类全部文章，不进主导航 |
| `/blog/<slug>/` | 暖纸 | 阅读页。返回到 `/articles/` |
| `/probe/` | 终端 | 实时探针 |
| `/map/` | 终端 | 旅行地图 |
| `/graph/` | 终端 | 知识图谱，独立页 |
| `/tools/` | 终端 | 外链工具卡 |
| `/lab/` | 终端 | 实验索引；真正实验在独立 origin |
| 404 | 终端 | 明确错误，不伪装成文章 |

侧栏打开后：顶部是搜索，下面是功能导航。搜索不是编号功能。浮层覆盖正文，不推开页面。浮层视觉跟当前页走：暖纸页上是暖纸浮层，终端页上是终端浮层。

## 4. 内容模型

唯一正文类型：文章（BlogPosting）。

感悟是一个 category，不单开类型。地点是数据，不是文章。工具是卡片 + 外链。关系用独立 relations，不上图数据库。

文章字段保持小而稳：title、description、date、category、tags、draft、places、正文。

地点：slug、名称、坐标、是否去过、地标。

对外 JSON-LD 用 BlogPosting / WebSite / Person，不自创词表。

## 5. 功能需求

### 5.1 首屏

- 每次刷新重新随机，不记住手选
- `?effect=<id>` 可复现
- 角落选择栏默认收起，展开后左右切换
- 粒子类效果用现成粒子库，不自研引擎
- 文章选择页页脚提供隐藏的回看入口

### 5.2 文章

- Markdown 为主，agent 写入
- 选择页按分类分块，每块最近 3–4 篇，日期倒序
- 「最热」不做
- 分类归档独立存在，不进主导航
- 阅读页常驻只有返回（到文章选择页）和侧栏入口
- 目录默认折叠，只做页内 H2/H3
- 上一篇 / 下一篇在评论前：同分类较新 / 较旧，分类尽头回退全站时间线
- 代码块要复制按钮
- 评论用 Giscus，放文末；pathname 映射；Announcements；strict。用站长自己的 GitHub 仓库。阅读无登录门槛，留言走 GitHub。
- 搜索结果可带匹配高亮摘要

### 5.3 实验室

- 主域只有索引
- 实验在独立域名，允许任意 JS
- 公网无上传，只有服务器侧 agent 能发布

### 5.4 探针

- 只读，实时，不存历史曲线
- 约 4～5 台
- 在线、CPU、内存、Swap、磁盘、负载；百分比展示
- 每台地区 + 当地时间，不做独立世界钟
- 告警只写本地日志

### 5.5 地图

- 平面、可缩放
- 未去过灰，去过点亮
- 放大到阈值才出地标，缩回世界尺度隐藏
- 底图第一版用 OSM 公共瓦片，必须能换成别家，不把一家写死进内容
- 地点相关文章可以链出去，但图谱是单独一页

### 5.6 知识图谱

- 独立页
- 只展示已确认关系
- 不在浏览器里推断或写回

### 5.7 工具

- 与文章、探针、地图、图谱同级
- 卡片：名称、一句说明、外链

### 5.8 音乐

- 全局，换主域页不断，默认收在侧栏
- 只能选预置台；清单在配置里，加一条多一个台
- 源在构建时解析；浏览器只用构建结果，访客不能添加
- 进站意图为播；被拦则待点击
- 进实验子域中断可以接受

### 5.9 主题与无障碍

- 手动覆盖优先，其次当地时间自动，再退到系统偏好
- 减少动效尊重系统，并在侧栏可手动降档

### 5.10 统计

- 第一版不做公开统计面板，不做最热
- 不为排序去记阅读量回写

## 6. 视觉与转场（产品层）

两套语言：

- 暖纸：文章选择、分类归档、阅读
- 终端：探针、地图、图谱、工具、实验室索引、404
- Hero 不继承这两套

转场：

- 切到阅读：一张纸舒缓翻开，要有纸背和折痕，不要快翻
- 切到功能页：粒子从四周涌入覆盖
- 暖纸之间：安静换页
- 终端之间：粒子直接挪到新位置，不要炸开再聚
- 动效关了或失败：直接到目标页

侧栏：收起是小点；打开从右侧滑出盖住内容。不要螺旋吸放，不要把正文挤走。

## 7. 非功能

### 7.1 性能

- 首屏只拉当前效果
- 功能库按页懒加载
- 移动端粒子有上限
- 观测组件不能比站点重

### 7.2 观测

- 主机：OpenTelemetry Collector + Prometheus + node_exporter
- 公共探针只拿缩减后的只读投影
- 站点错误、构建失败、播放失败写服务器本地日志，不接 Sentry 等 SaaS
- 平时可以不怎么看日志，但崩了要留得住

### 7.3 安全

- 管理面公网不开放
- 无匿名上传
- Prometheus 管理面 / 任意查询不对公网开放

### 7.4 备份与开源

- 文章与代码进 Git
- 部署配置与不可重建产物进 restic
- 主仓代码 MIT；文章、照片、实验各自声明版权
- 另有干净 template 分支，去掉个人域名、Giscus、服务器名单、电台真实地址

### 7.5 缓存

- 带 hash 的静态资源长缓存
- HTML 短缓存
- 可用 Cloudflare 免费层
- 发文后应让访客在合理时间内看到新文章

---

## 8. 明确不做

- 综合仪表盘首页
- 留言板 / 自建评论库
- 搜索服务器
- 图数据库
- Kubernetes / 服务网格
- 自研粒子引擎或 WebGL renderer
- 公网 Prometheus
- 第一版最热排序和公开统计面板
- 访客添加电台
- 第三方 APM
- 把实验页嵌进主域权限上下文保音乐

---

## 9. 验收一句话

打开站点先看到随机首屏；进入后是暖纸文章选择；侧栏能到探针、地图、图谱、工具、实验室；阅读好读；功能页是终端；换页有纸或粒子，但关动画也能用；机器状态看得到、查不穿；内容能备份、能开源成干净模板。
